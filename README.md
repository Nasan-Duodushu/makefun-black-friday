DealBoard — a Black Friday and Cyber Monday deal finder with 23 real, price-checked deals across Amazon, Walmart, Best Buy, Target and Nordstrom: search plus category, store and discount filters, three sorts, a "really a deal" verdict on every deal, a detail page with check time, verification source and same-product comparison across stores, and a phone layout. Static files, no network.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
